# DataForSEO LLM Plugins

Official DataForSEO plugins for LLM agents.

## Codex

Add this repository as a Codex plugin marketplace:

```bash
codex plugin marketplace add dataforseo/llm-plugins
```

Then open the Codex plugin browser and install **DataForSEO**. The plugin
connects to the hosted DataForSEO MCP server at:

```text
https://mcp.dataforseo.com/v3/mcp
```

Codex will prompt you to authenticate with DataForSEO during installation.
